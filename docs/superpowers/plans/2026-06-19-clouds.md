# Parallax Clouds Sky Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two-layer parallax-drifting blocky clouds to the gameplay sky, drawn behind all world tiles, with per-world-deterministic layouts.

**Architecture:** A new self-contained engine module `src/engine/clouds.h/.c` owns cloud state, generation (seeded by a djb2 hash of the world name), drift update, and screen-space parallax rendering. The `Game` struct gains a `Clouds` field; `main.c` calls init/update/render at the right points in the existing loop. No renderer, camera, world, or save-format changes.

**Tech Stack:** C11, SDL2, OpenGL (fixed-function), existing `Prng` and `renderer_draw_rect` / `renderer_begin_ui` primitives.

**Spec:** `docs/superpowers/specs/2026-06-19-clouds-design.md`

## Task 2: Implement `name_hash` + `clouds_init` (deterministic generation)

Generate the two cloud layers from a hash of the world name. Per spec §`clouds_init`.

**Files:**
- Modify: `src/engine/clouds.c`

**Reference facts (verified):**
- `prng_range(p, min, max)` is **inclusive** of `max` (returns `min + (int)(f*(max-min+1))`).
- `prng_float(p)` returns `[0,1)`.
- `prng_seed` maps a 0 seed to 1, so any hash value is safe.

- [ ] **Step 1: Replace the `clouds_init` stub and add the `name_hash` helper**

Replace the entire contents of `src/engine/clouds.c` with:

```c
#include "clouds.h"
#include "prng.h"
#include <math.h>

static uint32_t name_hash(const char *s) {
    uint32_t hash = 5381u;
    const unsigned char *p = (const unsigned char *)s;
    while (*p) {
        hash = hash * 33u + *p;
        p++;
    }
    return hash;
}

void clouds_init(Clouds *c, const char *world_name, int world_w, int world_h) {
    c->world_w = world_w;
    c->world_h = world_h;
    c->wrap_w = world_w;

    Prng rng;
    prng_seed(&rng, name_hash(world_name));

    for (int L = 0; L < CLOUD_LAYER_COUNT; L++) {
        c->count[L] = CLOUDS_PER_LAYER;
        int size_percent = (L == 0) ? 100 : 60;
        float scale = size_percent / 100.0f;
        for (int i = 0; i < CLOUDS_PER_LAYER; i++) {
            Cloud *cl = &c->layer[L][i];
            cl->world_x = (float)prng_range(&rng, 0, world_w);
            cl->world_y = (float)prng_range(&rng, 0, (world_h * 2) / 5);
            if (L == 0) {
                cl->drift_speed = 10.0f + 6.0f * prng_float(&rng);
            } else {
                cl->drift_speed = 4.0f + 4.0f * prng_float(&rng);
            }
            cl->size_scale = size_percent;
            cl->part_count = prng_range(&rng, 5, CLOUD_MAX_PARTS);
            for (int p = 0; p < cl->part_count; p++) {
                int base_ox = prng_range(&rng, -32, 32);
                int base_oy = prng_range(&rng, -12, 12);
                int base_w = prng_range(&rng, 12, 28);
                int base_h = prng_range(&rng, 12, 28);
                cl->ox[p] = (int)(base_ox * scale);
                cl->oy[p] = (int)(base_oy * scale);
                cl->w[p]  = (int)(base_w  * scale);
                cl->h[p]  = (int)(base_h  * scale);
            }
        }
    }
}

void clouds_update(Clouds *c, float dt) {
    (void)c; (void)dt;
}

void clouds_render(Clouds *c, Renderer *r, const Camera *cam) {
    (void)c; (void)r; (void)cam;
}
```

## Task 4: Implement `clouds_render` (parallax + screen-space projection)

Per spec §`clouds_render`: wrap each cloud's `world_x` over `wrap_w`, combine drift + camera parallax into screen-space x/y, cull off-screen clouds, draw each part with `renderer_draw_rect`. Wrap the whole pass in `renderer_begin_ui`/`renderer_end_ui` to establish a guaranteed screen-space ortho (since `renderer_clear` does not set up projection).

**Files:**
- Modify: `src/engine/clouds.c`

**Reference facts (verified):**
- `renderer_begin_ui(r)` sets `g_screen_w`/`g_screen_h` via `renderer_get_size` and sets a 1:1 `glOrtho(0, g_screen_w, g_screen_h, 0, ...)`. So `g_screen_w` is current after calling it.
- `renderer_draw_rect(r, x, y, w, h, r, g, b, a)` draws an alpha-blended quad.
- Per-layer config (from spec): near (idx 0) parallax 0.50, white (1,1,1), alpha 0.90; far (idx 1) parallax 0.25, light-gray (0.85,0.85,0.90), alpha 0.60.

- [ ] **Step 1: Replace the `clouds_render` stub**

```c
void clouds_render(Clouds *c, Renderer *r, const Camera *cam) {
    static const float parallax[CLOUD_LAYER_COUNT] = { 0.50f, 0.25f };
    static const float col_r[CLOUD_LAYER_COUNT]   = { 1.00f, 0.85f };
    static const float col_g[CLOUD_LAYER_COUNT]   = { 1.00f, 0.85f };
    static const float col_b[CLOUD_LAYER_COUNT]   = { 1.00f, 0.90f };
    static const float col_a[CLOUD_LAYER_COUNT]   = { 0.90f, 0.60f };

    renderer_begin_ui(r);
    for (int L = 0; L < CLOUD_LAYER_COUNT; L++) {
        for (int i = 0; i < c->count[L]; i++) {
            Cloud *cl = &c->layer[L][i];
            float eff_x = fmodf(cl->world_x, (float)c->wrap_w);
            if (eff_x < 0.0f) eff_x += (float)c->wrap_w;
            int screen_x = (int)(eff_x - (cam->x - c->world_w / 2.0f) * parallax[L]);
            int screen_y = (int)(cl->world_y - (cam->y - c->world_h / 2.0f) * parallax[L]);
            if (screen_x < -CLOUD_MAX_WIDTH || screen_x > g_screen_w + CLOUD_MAX_WIDTH) {
                continue;
            }
            for (int p = 0; p < cl->part_count; p++) {
                renderer_draw_rect(r, screen_x + cl->ox[p], screen_y + cl->oy[p],
                                   cl->w[p], cl->h[p],
                                   col_r[L], col_g[L], col_b[L], col_a[L]);
            }
        }
    }
    renderer_end_ui(r);
}
```

- **Behind world:** Clouds are occluded by terrain/tiles — they never draw over a foreground block or the player.
- **Two depth layers:** A brighter/larger near layer and a dimmer/smaller far layer are both visible.
- **Parallax:** Move the player left/right (A/D). The clouds shift in the opposite direction, and the near layer moves noticeably faster than the far layer.
- **Vertical parallax:** Move the camera vertically (jump/fall or climb). Clouds shift vertically at less than 1:1 with the camera.
- **Drift:** Watch the sky for ~10 seconds. Clouds slowly drift horizontally on their own (even when the player stands still).
- **Wrap:** Wait until a cloud reaches a screen edge — it should re-appear from the opposite side rather than vanishing.
- **Zoom invariant:** Scroll-zoom in/out. Cloud size on screen does NOT change (they are screen-space), while world tiles zoom normally.
- **Not on menu:** Press ESC to return to the world-select menu. The menu screen has its dark background and **no clouds**.
